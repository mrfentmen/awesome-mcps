# stoic-quotes-mcp

Quotes from Epictetus, Seneca, Marcus Aurelius, and other Stoic thinkers from the Stoic Quotes API.

This file is self contained. It reads public data only and never writes to the machine. All output is bounded and honest about what could not be fetched.

## Tools


* `random`  One random Stoic quote.
* `many`  Several quotes.

## Usage

```bash
npm install
npm run build
node dist/index.js
```
